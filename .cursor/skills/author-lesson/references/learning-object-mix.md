# Learning-object mix (blueprint §9.3)

Use the smallest combination that proves mastery:

- **Concept model:** property, actors, trust, state, failure conditions
- **Mechanism lab:** what a browser, framework, OS, protocol, or cloud control actually guarantees
- **Break/fix lab:** authorized isolated target; root-cause fix and tests
- **Design exercise:** architectures under explicit constraints; trade-offs
- **Code review:** security-sensitive data/authority/state in a realistic diff
- **Verification lab:** negative, property, fuzz, concurrency, or failure evidence
- **Operations exercise:** signal, alert, revocation, response, restore, or disclosure
- **Transfer challenge:** novel variation without a step-by-step scaffold
