# Seven-step loop (blueprint §3)

Every substantive module’s lesson inventory must plan for:

| Step | Learner action | Required output |
|---|---|---|
| 1. Property | State what must remain true | Precise security invariant |
| 2. Model | Assets, actors, authority, boundaries, state, time | Small system/threat model |
| 3. Break | Smallest representative failure in an authorized lab | Evidence of cause and impact |
| 4. Build | Smallest trustworthy mechanism that restores the invariant | Secure implementation or design change |
| 5. Verify | Normal, negative, abuse, and failure cases | Tests and review evidence |
| 6. Operate | Log, alert, rotate, revoke, recover | Detection/recovery notes or runbook |
| 7. Generalize | When the control works, when it does not, trade-offs | Transfer exercise and standards mapping |
