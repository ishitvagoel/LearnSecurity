# Structurally fixed authority policy

The fixed fixture resolves current subject and stored object state, matches explicit actions, preserves tenant scope when expanding the admin role, requires the documented distinct current approvals for the illustrative export case, and denies unknown authority states. Read, list, delete, and export-decision operations consume the policy decision before their modeled effect.

This is a small in-memory teaching model, not production authorization assurance. It has no HTTP boundary, database, cryptographic capability, token, cache, queue, worker, transaction, or cloud administrator. Every one of those additions reopens the authority and complete-mediation review.

Decision metadata intentionally excludes note bodies, credentials, tokens, and real personal data. The fixture performs no network, filesystem, process, credential, or production operation.
