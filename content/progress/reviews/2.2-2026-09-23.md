## Blocker

Per the task's instruction to build my own fake rather than only re-running the documented ones, I replaced `fixed/app.py`'s version check:

```python
# real fixed code
if tls_version not in _ACCEPTED_TLS_VERSIONS:   # _ACCEPTED_TLS_VERSIONS = {"1.2", "1.3"}

```

```python
if tls_version < "1.2":

```

This passes both existing version-related tests (`"1.2"` accepted, `"1.1"` rejected — `"1.1" < "1.2"` is true lexicographically) exactly as the real fix does. I ran the full suite against it:

```

```

**All fourteen tests pass, including both hostname anti-fake tests and the newly-added untrusted-CA anti-fake test.** No test in either file sends a `tls_version` value outside `{"1.1", "1.2", "1.3"}`, so nothing distinguishes "exact membership in the accepted set" from "lexicographically at or above the oldest accepted version" — a string like `"9"`, `"2.0"`, or `"A"` sorts above `"1.2"` in Python string comparison (`"9" > "1.2"` is `True`; so is `"A" > "1.2"`, since `'A'` (65) > `'1'` (49) in ASCII) and would be accepted as trustworthy by this fake even though it is not one of the two versions this module's own claim, README, and lessons name as accepted.
