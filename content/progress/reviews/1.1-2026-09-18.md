## One real finding: a test-count inaccuracy in `lessons/03-local-hashed-claim.md`

I found this by cross-checking the lesson's own accounting against my actual pytest run, not by trusting either.

`03-local-hashed-claim.md` states: "four passing unit tests alongside the one failure (`test_mechanism_slogan_is_rejected`, `test_public_target_is_rejected_but_local_lab_is_allowed`, and two anti-fake tests covered in [05-forbidden-outcomes.md](05-forbidden-outcomes.md))".

This is wrong on two counts, both checkable:

1. My actual run of the vulnerable fixture shows **5 passed, 1 failed** (6 tests total), not "four passing... alongside the one failure" (5 total).
2. `05-forbidden-outcomes.md` itself describes **three** anti-fake tests, not two: its own section header sequence is "carries two anti-fake tests" (`test_field_presence_alone_does_not_pass`, `test_field_complete_but_causally_shallow_claim_does_not_pass`) followed immediately by "**A third anti-fake test**, `test_five_padded_duplicate_rows_do_not_pass`..." — and closes with "Passing all **six** tests in this lab...". Lesson 03's parenthetical undercounts by exactly the one anti-fake test (the newly-added `test_five_padded_duplicate_rows_do_not_pass`) that this very pass introduced.

The likely mechanism: the anti-fake test was added late in this pass (it is the pass's own headline lab fix), and lesson 03's "confirm the environment is healthy" paragraph was not updated to account for the sixth test. This is a one-lesson, one-sentence inaccuracy — it does not affect the lab's actual behavior, the coverage contract, the item bank, or any other lesson (05, which is the lesson actually walking through the anti-fake tests, states the count correctly) — but it is a factual claim in learner-facing prose about what the learner should observe, and it is wrong as written. A learner who runs the command and counts five passing tests, expecting the lesson's stated four, has correctly run the lab and has been told their environment might be unhealthy when it is not.

**To close:** in `lessons/03-local-hashed-claim.md`, change "four passing unit tests alongside the one failure (`test_mechanism_slogan_is_rejected`, `test_public_target_is_rejected_but_local_lab_is_allowed`, and two anti-fake tests covered in [05-forbidden-outcomes.md](05-forbidden-outcomes.md))" to name five passing tests / three anti-fake tests (or simply "five passing unit tests alongside the one failure... and three anti-fake tests covered in 05-forbidden-outcomes.md").
