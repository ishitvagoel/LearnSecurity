# Examiner notes — 4.3 (not learner-facing)

## Property

A session token in the query string is not an acceptable session. Access tokens belong in Cookie (HttpOnly, 2.3) or Authorization, never in logs and Referer.

## Lab

- `labs/4.3/4.3-lab/vulnerable/` must fail: Session established from a query-string token
- `labs/4.3/4.3-lab/fixed/` must pass.
- Root cause: Token placed in a logged, shared channel.

## Seeded review intended findings

- session_from_request uses query
- JWT in localStorage as “SPA best practice” 2016 blog
- No Referer policy
- Tokens printed in uvicorn logs

## Transfer

Reject answers that name Top 10 / CWE Top 25 items as the definition of security.
Require a system-specific invariant, attacker, trust, residual risk.
Acceptable transfer direction: Magic-link email (still a URL token — time-bound, one-time, 6.6).

## Operate

Accept a detect/recover note that does not log bodies/secrets. Example signal: query_token_rejected; log-redact gateway.
