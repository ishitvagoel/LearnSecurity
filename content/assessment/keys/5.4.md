# Examiner notes — 5.4 (not learner-facing)

## Property

Client-supplied X-Forwarded-Proto is not TLS. Channel authenticity is the server socket (or a bound proxy). ASVS anchors: `v5.0.0-12.2.1`, `v5.0.0-12.1.1`, `v5.0.0-12.3.2`; `v5.0.0-12.1.4` and `v5.0.0-12.1.5` are **Level 3, advanced**. RFC 9846 final. Pinning is a trade-off.
