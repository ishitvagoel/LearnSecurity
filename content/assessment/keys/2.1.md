# Examiner notes — 2.1 (not learner-facing)

## Property

If a note JSON object repeats the tenant key, ingest must reject (or both the ACL decision and the stored row must see the same tenant). A parser that keeps the first key for ACL and the last key for storage is a confidentiality failure caused by disagreement, not by missing login.

Bytes → characters → tokens → values is the mental model. RFC 8259 unique names are SHOULD. CPython `json.loads` last-wins. ASVS `v5.0.0-1.5.3` is Level 3 parser-consistency; do not treat it as an undisclosed Phase 1 baseline. `v5.0.0-1.1.1`, `v5.0.0-2.2.1`, and `v5.0.0-2.2.2` are the taught V1/V2 anchors.
