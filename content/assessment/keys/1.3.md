# Examiner notes — 1.3 (not learner-facing)

## Property

A browser-supplied header such as X-SecureCollab-Internal is on the untrusted side of the API boundary. It must not dump all tenants’ notes. Only a worker bound in-process (or a real service identity later) may export.

## Lab

- `labs/1.3/1.3-trust-boundaries/vulnerable/` must fail: Client internal header dumps all tenants' notes
- `labs/1.3/1.3-trust-boundaries/fixed/` must pass.
- Root cause: Transitive trust: the handler believed a string that crossed the boundary.

## Seeded review intended findings

- if request.headers.get('X-SecureCollab-Internal'): return all_notes()
- SECURITY.md claims “API is private because we use HTTPS”
- No test for header present + worker_bound false
- Trusting X-Forwarded-For as client identity
