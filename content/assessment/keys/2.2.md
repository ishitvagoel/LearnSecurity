# Examiner notes — 2.2 (not learner-facing)

## Property

A cache entry for `GET /notes/n1` must include the bound tenant in the key. Tenant B must not receive Tenant A’s body. TLS 1.3 (RFC 9846) authenticates a hop; it is not the cache-key property. RFC 9110 cacheability/`Vary` do not insert tenant.

ASVS anchors: `v5.0.0-4.1.3` (forwarded headers not end-user overridable), `v5.0.0-12.2.1` (TLS to external HTTP), `v5.0.0-14.2.2` (sensitive data in app/load-balancer caches), `v5.0.0-14.3.2` (browser `no-store`). `v5.0.0-14.2.5` is Level 3 web-cache-deception; do not treat it as an undisclosed Phase 1 baseline.
