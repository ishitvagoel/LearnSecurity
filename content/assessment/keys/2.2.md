# Examiner notes — 2.2 (not learner-facing)

## Property

A cache entry for GET /notes/n1 must include the bound tenant in the key. Tenant B must not receive tenant A’s body. HTTPS does not imply this.

## Lab

- `labs/2.2/2.2-request-path/vulnerable/` must fail: Shared cache returns tenant A's body to tenant B
- `labs/2.2/2.2-request-path/fixed/` must pass.
- Root cause: Key omitted the subject’s tenant; shared store.

- Key is path only
- Comment “TLS so cache is safe”
