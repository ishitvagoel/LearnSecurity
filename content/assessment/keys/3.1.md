# Examiner notes — 3.1 (not learner-facing)

## Property

Note bodies are Confidential. An application log line for `note_read` must not contain the body. Classification is a field × sink rule. Labels in Confluence do not enforce this.

ASVS anchors: `v5.0.0-14.1.1`, `v5.0.0-14.1.2`, `v5.0.0-16.2.5`. CSF 2.0 Identify is an outcome family. Privacy Framework 1.1 is draft if cited.

## Lab

- `labs/3.1/3.1-lab/vulnerable/` must fail `test_note_body_is_not_logged`
- `labs/3.1/3.1-lab/fixed/` must pass (no body substring; redaction marker present)
- Root cause: body treated as debug context
