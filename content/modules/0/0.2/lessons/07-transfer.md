# Transfer: a clinic capability diagnostic

**Kind:** transfer-challenge
**Loop step:** 7 Transfer

A clinic-booking team wants to onboard a developer quickly. They demonstrate Python and Git, but not browser or SQL work. Design a record that assigns `bridge-browser` and `bridge-sql` while keeping tenant isolation, input handling, accessibility, and the first security check-in required.

Explain why a vendor certificate or 100% quiz cannot replace those cells. The diagnostic should be reproducible from its evidence map and should not require access to a clinic LMS.

## Practice

Write the evidence map, expected bridge list, and the separate Gate 1 evidence still required. Name one residual risk if the team memorized the quiz instead of demonstrating the capability.
